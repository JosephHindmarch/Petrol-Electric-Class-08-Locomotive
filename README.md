# Petrol-Electric-Class-08-Locomotive
In this repository I outline the Design and construction of a petrol-electric 5 inch gauge garden railway locomotive which I built between 2022 and 2025. The locomotive was designed to replicate the Full-Size Class 08 shunter, but in reduced 5 inch gauge scale. Originally my model Class 08 was constructed with a battery power system, however after some design changes I implemented a petrol electric power system. The use of a petrol electric power system enabled the model to accurately reproduce the power system in the Full-Size locomotive. 

The project began by creating detailed drawings for the main chassis components. To produce the drawings I used my hand technical drawing skills because I did not have access to CAD software at the time. I have included some of the key drawings for the locomotive chassis in the file tree under **"LocomotiveDrawings"**. This document highlights certain components and briefly explains how they fit together.

Once I had the initial drawings I began to machine the chassis components in my home workshop. Every chassis component except the motors, chains and sprockets were machined on a manual Lathe and Milling Machine by myself.
